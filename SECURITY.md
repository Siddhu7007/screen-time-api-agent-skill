# Security Notes

This repository includes agent skill content and optional helper scripts.

- Treat skills like code. Review before installation and execution.
- Scripts are optional; run them only when a user explicitly asks and the context requires them.
- Do not add secrets (API keys, tokens, credentials) to this repository.
- Do not run commands that require secrets unless the operator explicitly opts in.
- Prefer least-privilege execution and inspect command arguments before running scripts from untrusted contexts.

If you discover a security issue, open a private report via GitHub Security Advisories when possible.
